Road Voice Privacy Policy

Effective and last updated: August 12, 2026

Road Voice is a voice assistant for Android and Android Auto. This policy explains what data the app processes, why it is needed, and the choices available to you.

English

Who operates Road Voice

Road Voice is operated by its independent developer. For privacy questions or requests, contact halcightjp@gmail.com.

Data we process

  • Voice and conversation data. When you start a voice session, microphone audio, conversation content, tool requests, tool results, and web-search queries are transmitted to the OpenAI API to provide realtime responses and requested features.
  • Optional location and place-search data. Road Voice requests foreground location permission only. If you grant permission and ask for a location-based feature, the app may process your latitude, longitude, accuracy, and observation time. These details are sent to OpenAI to answer the tool request. For current-location weather, coordinates are also sent to Open-Meteo. For named-place weather, the place name is sent to Open-Meteo for geocoding. A place-search query, optional current-location bias, and returned place candidates are processed by Google Places when you ask to find a destination.
  • OpenAI API key. The key you enter is encrypted on your device with Android Keystore-backed AES-GCM storage and is sent to OpenAI only to authenticate API requests. The developer does not receive or store your key.
  • Local settings and artifacts. Interface language, voice and noise-reduction selections, and generated Markdown conversation summaries are stored locally on your device. During each phone or Android Auto voice session, Road Voice temporarily creates and incrementally updates a local Markdown diagnostic report containing the session origin, selected audio route and noise-reduction mode, stop source, session, VAD and barge-in event timing, and aggregate audio-signal measurements such as byte count, chunk interval, RMS, peak, and clipping rate. A diagnostic report does not contain raw audio, a transcript, an API key, tool arguments, model responses, or location. A Markdown file leaves the app only when you explicitly share it through Android's share interface.
  • Technical request data. Service providers may automatically process network information such as an IP address and request metadata under their own policies.

Why we process data

Data is processed only to provide the feature you request: realtime voice conversation, web search, weather, current location, connection testing, local preferences, and local Markdown artifacts. Road Voice has no developer-operated analytics, advertising, account, or cloud-storage service, and the developer does not sell your personal data.

Service providers

  • OpenAI. Provides realtime voice responses and web search. OpenAI states that API data is not used to train its models unless the API customer opts in. OpenAI may retain abuse-monitoring logs containing customer content for up to 30 days by default. Road Voice sends Responses API requests with storage disabled. See OpenAI's Privacy Policy and API data controls.
  • Open-Meteo. Provides weather and place-geocoding data. Its free API logs may include IP addresses and geographic coordinates for troubleshooting and states that individual logs are deleted after 90 days. See Open-Meteo Terms & Privacy.
  • Google Places. Provides destination search and place candidates when requested. See Google's Privacy Policy.
  • Google Play services and Android. Supply device location and operating-system features. See Google's Privacy Policy.

Retention and deletion

Road Voice does not send data to a developer-operated backend and keeps no developer-side server copy. Local preferences and artifacts remain until you remove them, clear the app's data, or uninstall the app. You can remove the saved API key and delete individual artifacts in the app. Third-party providers retain data according to their policies described above.

Your choices

You may decline or revoke microphone and location permissions in Android settings. Location features will not run without the applicable permission. You may remove your API key, delete generated artifacts, clear all app data, or uninstall Road Voice at any time.

Security

Road Voice uses encrypted HTTPS/WSS connections for service requests and encrypts the API key at rest using Android Keystore-backed cryptography. No method of storage or transmission is completely secure, and storing a long-lived API key on a client device carries extraction risk.

Children

Road Voice is not directed to children under 13, and the developer does not knowingly collect personal data from children.

International processing and changes

Third-party providers may process data in countries other than your own. We may update this policy when app features or legal requirements change. The revised policy will be posted at this URL with a new update date.

简体中文

运营者与联系方式

Road Voice 由独立开发者运营。如有隐私问题或请求，请联系 halcightjp@gmail.com。

我们处理的数据

  • 语音与对话数据。当你开始语音会话时，麦克风音频、对话内容、工具请求、工具结果和网页搜索请求会发送至 OpenAI API，用于提供实时回复和你请求的功能。
  • 可选的位置与地点搜索信息。Road Voice 只申请前台定位权限。当你授权并主动请求位置相关功能时，App 可能处理纬度、经度、精度和定位时间，并将这些信息发送给 OpenAI 以完成工具请求。查询当前位置天气时，坐标也会发送给 Open-Meteo；查询指定地点天气时，地点名称会发送给 Open-Meteo 进行地理编码。当你要求查找目的地时，地点搜索词、可选的当前位置偏向和返回的地点候选会由 Google Places 处理。
  • OpenAI API Key。你输入的 Key 使用 Android Keystore 支持的 AES-GCM 加密保存在设备上，仅为验证 API 请求而发送给 OpenAI。开发者不会收到或保存你的 Key。
  • 本地设置与文件。界面语言、声音与降噪选择，以及生成的 Markdown 对话摘要只保存在设备本地。每次手机或 Android Auto 语音对话期间，Road Voice 会临时创建并增量更新一份本地 Markdown 诊断报告，记录会话来源、所选音频路由与降噪模式、停止来源、会话、VAD 与打断事件时间，以及字节数、音频块间隔、RMS、峰值和削波率等聚合音频信号指标。诊断报告不包含原始音频、逐字稿、API Key、工具参数、模型回复或位置。只有当你通过 Android 分享界面主动分享时，Markdown 文件才会离开 App。
  • 技术请求数据。服务提供方可能根据其政策自动处理 IP 地址、请求元数据等网络信息。

处理目的

数据仅用于提供你请求的功能，包括实时语音对话、网页搜索、天气、当前位置、连接测试、本地偏好设置和本地 Markdown 文件。Road Voice 不使用开发者自建的分析、广告、账户或云存储服务；开发者不会出售你的个人数据。

服务提供方

  • OpenAI。提供实时语音回复和网页搜索。OpenAI 说明，除非 API 客户主动选择加入，否则 API 数据不会用于训练其模型；默认情况下，可能包含客户内容的滥用监测日志最多保留 30 天。Road Voice 调用 Responses API 时会关闭存储。请参阅 OpenAI 隐私政策和 API 数据控制说明。
  • Open-Meteo。提供天气与地点地理编码。其免费 API 的故障排查日志可能包含 IP 地址和地理坐标，并说明会在 90 天后删除单条日志。请参阅 Open-Meteo 条款与隐私。
  • Google Places。在你提出请求时提供目的地搜索和地点候选。请参阅 Google 隐私政策。
  • Google Play 服务与 Android。提供设备定位和操作系统功能。请参阅 Google 隐私政策。

保留与删除

Road Voice 不向开发者自建后台发送数据，开发者端不保留服务器副本。本地偏好和文件会保留至你主动删除、清除 App 数据或卸载 App。你可在 App 内移除 API Key 并逐个删除文件。第三方服务按上述各自政策保留数据。

你的选择

你可以拒绝授权或在 Android 设置中撤销麦克风和定位权限；没有相应权限时，位置功能不会运行。你也可以随时移除 API Key、删除生成的文件、清除全部 App 数据或卸载 Road Voice。

安全

Road Voice 通过加密的 HTTPS/WSS 连接请求服务，并使用 Android Keystore 支持的加密方式保护本地 API Key。但任何存储或传输方式都无法保证绝对安全，在客户端设备保存长期 API Key 仍存在被提取的风险。

儿童

Road Voice 不面向 13 岁以下儿童，开发者不会有意收集儿童的个人数据。

跨境处理与政策更新

第三方服务提供方可能在你所在国家或地区之外处理数据。当 App 功能或法律要求变化时，我们可能更新本政策，并在本网址公布新的更新日期。

日本語

運営者と連絡先

Road Voice は独立開発者によって運営されています。プライバシーに関するご質問やご依頼は、halcightjp@gmail.com までご連絡ください。

処理するデータ

  • 音声と会話データ。音声セッションを開始すると、マイク音声、会話内容、ツールのリクエストと結果、ウェブ検索クエリが OpenAI API に送信され、リアルタイム応答と要求された機能の提供に使用されます。
  • 任意の位置情報と場所検索データ。Road Voice が要求するのはフォアグラウンド位置情報の権限のみです。許可したうえで位置情報を使う機能を要求すると、緯度、経度、精度、取得時刻を処理し、ツール要求への回答のため OpenAI に送信する場合があります。現在地の天気では座標を Open-Meteo にも送信し、地名を指定した天気では地理検索のため地名を Open-Meteo に送信します。目的地の検索を依頼した場合、検索語、任意の現在地バイアス、返された場所候補が Google Places によって処理されます。
  • OpenAI API キー。入力したキーは Android Keystore によって保護された AES-GCM で端末内に暗号化保存され、API リクエストの認証に限って OpenAI に送信されます。開発者がキーを受信または保存することはありません。
  • ローカル設定とファイル。表示言語、音声とノイズ低減の選択、生成した Markdown 会話要約は端末内だけに保存されます。スマートフォンまたは Android Auto の各音声セッション中、Road Voice は一時的にローカル Markdown 診断レポートを作成して段階的に更新します。レポートにはセッションの開始元、選択した音声経路とノイズ低減モード、終了要因、セッション、VAD と割り込みイベントの時刻、バイト数、チャンク間隔、RMS、ピーク、クリッピング率などの集計音声信号指標が含まれます。診断レポートには生の音声、文字起こし、API キー、ツール引数、モデルの応答、位置情報は含まれません。Android の共有画面から明示的に共有した場合に限り、Markdown ファイルがアプリ外に送られます。
  • 技術的なリクエストデータ。サービス提供者は、それぞれのポリシーに従い、IP アドレスやリクエストのメタデータなどのネットワーク情報を自動的に処理する場合があります。

利用目的

データは、リアルタイム音声会話、ウェブ検索、天気、現在地、接続テスト、ローカル設定、ローカル Markdown ファイルなど、利用者が要求した機能を提供するためだけに処理されます。Road Voice には開発者が運営する分析、広告、アカウント、クラウド保存サービスはなく、開発者が個人データを販売することはありません。

サービス提供者

  • OpenAI。リアルタイム音声応答とウェブ検索を提供します。OpenAI は、API 顧客がオプトインしない限り API データをモデルの学習に使用せず、顧客コンテンツを含む可能性のある不正利用監視ログを標準で最大 30 日間保持する場合があると説明しています。Road Voice は Responses API の保存を無効にして送信します。OpenAI プライバシーポリシーおよび API データ管理をご覧ください。
  • Open-Meteo。天気と地名の地理検索を提供します。無料 API のトラブルシューティング用ログには IP アドレスや地理座標が含まれることがあり、個別ログは 90 日後に削除すると説明しています。Open-Meteo の利用規約とプライバシーをご覧ください。
  • Google Places。依頼された目的地検索と場所候補を提供します。Google プライバシーポリシーをご覧ください。
  • Google Play 開発者サービスと Android。端末の位置情報と OS 機能を提供します。Google プライバシーポリシーをご覧ください。

保存期間と削除

Road Voice は開発者運営のバックエンドにデータを送信せず、開発者側のサーバーコピーを保持しません。ローカル設定とファイルは、利用者が削除するか、アプリデータを消去するか、アプリをアンインストールするまで保持されます。アプリ内で保存済み API キーを削除し、個々のファイルを削除できます。第三者サービスは上記の各ポリシーに従ってデータを保持します。

利用者による選択

マイクと位置情報の権限を許可しないこと、または Android の設定から取り消すことができます。必要な権限がない場合、位置情報機能は実行されません。API キーの削除、生成ファイルの削除、全アプリデータの消去、Road Voice のアンインストールもいつでも行えます。

セキュリティ

Road Voice はサービスへのリクエストに暗号化された HTTPS/WSS 接続を使用し、Android Keystore による暗号技術で保存 API キーを保護します。ただし、保存や送信の方法に絶対的な安全性はなく、クライアント端末に長期 API キーを保存することには抽出リスクがあります。

子ども

Road Voice は 13 歳未満の子どもを対象としておらず、開発者が子どもの個人データを故意に収集することはありません。

国外での処理と変更

第三者サービス提供者は、利用者の国や地域以外でデータを処理する場合があります。アプリ機能や法的要件が変わった場合、本ポリシーを更新することがあります。更新時は、この URL に新しい更新日とともに掲載します。
